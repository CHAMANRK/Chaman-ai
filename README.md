
# Chaman AI

**Chaman AI** is a public, agentic AI chat assistant built by **Najeef**. It runs on a Vercel deployment and uses open‑source LLMs via Groq, OpenRouter, Cerebras, and Mistral APIs.

## Features

- **Agentic actions**: live web search, Python sandbox execution, Termux bridge commands, Quran ayat quiz, and more.
- **Hinglish UI**: friendly, casual tone with Hindi‑English mix.
- **Open‑source stack**: no proprietary AI vendor lock‑in.
- **Easy setup**: Termux bridge for device‑side operations.

## Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/chaman-ai.git
   cd chaman-ai
   ```
2. **Deploy to Vercel** (or run locally)
   - Sign up at https://vercel.com
   - Import the repo and deploy.
3. **Configure Termux Bridge** (optional, for device actions)
   - Follow the **Termux Bridge Setup Guide** (see UI description).
   - Ensure the bridge is **connected** in Settings → Termux Bridge.

## Usage

- Open the app at `https://chaman-ai.vercel.app/`.
- Interact in **Hinglish**; the assistant will:
  - Perform live web searches when needed.
  - Run Python code in a sandbox for calculations.
  - Execute shell commands on your Termux device (if bridge is connected).
  - Host Quran ayat quizzes.
